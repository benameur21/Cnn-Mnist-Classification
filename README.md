# Improving a CNN for Handwritten Digit Recognition

## Objective

Improve a CNN model for handwritten digit recognition using the MNIST dataset, with a maximum of 5 epochs per experiment.

## Dataset

* 60,000 training images and 10,000 test images
* Image size: 28 × 28 pixels
* Grayscale images
* 10 classes (digits 0–9)

## Tasks

1. Build and evaluate the initial CNN.
2. Improve the CNN progressively:

   * V1: 16 filters with a 3 × 3 kernel
   * V2: MaxPooling 2 × 2
   * V3: Add a second convolutional block with 32 filters
   * V4: Add a Dense layer with 128 neurons
3. Design a custom CNN and evaluate its performance.
4. Test the model on a personal handwritten digit image.

## Technologies

* Python
* TensorFlow / Keras
* NumPy and Matplotlib
* Pillow (PIL)
* Jupyter Notebook / VS Code

## Results

Compare validation accuracy across architectures and evaluate the final model on the test dataset and a personal digit image.
